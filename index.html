AI Health Screener & Lab Report Explainer

ระบบวิเคราะห์และอธิบายผลตรวจสุขภาพด้วย AI ช่วยให้ผู้ใช้ทั่วไปเข้าใจค่าตรวจเลือด (เช่น Glucose, Cholesterol, LDL, HDL) ได้ง่ายขึ้น โดยใช้ Gemini API อ่านและแปลผลจากภาพผลตรวจ พร้อมคำแนะนำเบื้องต้น

ระบบวิเคราะห์และอธิบายผลตรวจสุขภาพด้วย AI ที่ออกแบบมาเพื่อแก้ปัญหาผู้ใช้ทั่วไปที่ไม่สามารถอ่านและเข้าใจผลตรวจเลือดของตัวเองได้ เนื่องจากมีศัพท์ทางการแพทย์ที่ซับซ้อน (เช่น LDL, HDL) และไม่ทราบค่ามาตรฐานของแต่ละตัว ทำให้ต้องเสียเวลาค้นหาข้อมูลเองและอาจเข้าใจผิดพลาดได้ ระบบนี้เปลี่ยนขั้นตอนการตีความผลตรวจจากที่ต้องทำเองทั้งหมด ให้กลายเป็นระบบอัตโนมัติที่เข้าใจง่ายภายในไม่กี่วินาที โดยใช้ Gemini API อ่านค่าจากภาพผลตรวจโดยตรงแบบ Multimodal วิเคราะห์ค่าทางการแพทย์ด้วยกฎมาตรฐาน (Rule-based) แล้วให้ AI แปลผลเป็นภาษาที่คนทั่วไปเข้าใจได้ พร้อมคำแนะนำเบื้องต้น ตัวเว็บแอปพัฒนาและรันบน Google Colab แล้วเปิดให้เข้าถึงได้ผ่าน ngrok ช่วยลดเวลาและความซับซ้อนในการตีความข้อมูลด้วยตนเอง

  • อัปโหลดภาพผลตรวจสุขภาพ แล้วให้ Gemini API อ่านและดึงข้อความ/ตัวเลขจากใบตรวจสุขภาพโดยตรงแบบ Multimodal โดยไม่ต้องผ่าน OCR แยกขั้นตอน
  • วิเคราะห์ค่าทางการแพทย์ (Glucose, Cholesterol, LDL, HDL) ด้วยกฎมาตรฐาน (Rule-based System) เพื่อเพิ่มความแม่นยำและความน่าเชื่อถือของผลวิเคราะห์
  • Gemini API แปลผลตรวจเป็นภาษาที่เข้าใจง่าย พร้อมคำแนะนำเบื้องต้น โดยดึงค่าตรวจและอธิบายผลเป็นภาษาที่คนทั่วไปเข้าใจได้
  • ออกแบบ Prompt Engineering เพื่อให้ AI อธิบายผลตรวจด้วยภาษาที่เข้าใจง่าย หลีกเลี่ยงศัพท์ทางการแพทย์ที่ซับซ้อน พร้อมสรุปความเสี่ยงสั้นๆ และคำแนะนำการดูแลเบื้องต้น
  • พัฒนาเป็นเว็บแอปรันบน Google Colab และเปิดให้เข้าถึงได้ผ่าน ngrok เพื่อทดสอบระบบแบบใช้งานจริง
  • จำกัดขอบเขตค่ามาตรฐานสุขภาพไว้ที่ 4 ค่าหลัก ได้แก่ Glucose, Cholesterol, LDL และ HDL เพื่อให้ระบบทำงานได้จริงและแม่นยำภายในเวลาที่กำหนด

ระบบตรวจจับสมาธิของผู้ใช้งาน
(Focus Monitoring System)

ระบบตรวจจับสมาธิของผู้ใช้งาน ใช้เซนเซอร์วัดแสง การเคลื่อนไหว และเสียงรอบตัว เพื่อประเมินสภาพแวดล้อมและแจ้งเตือนเมื่อไม่เหมาะสมต่อการมีสมาธิ พร้อมแสดงผลผ่าน Dashboard แบบเรียลไทม์

ระบบตรวจจับสมาธิของผู้ใช้งานที่ใช้เซนเซอร์วัดแสง การเคลื่อนไหว และเสียงรอบตัว เพื่อประเมินว่าสภาพแวดล้อมในขณะนั้นเหมาะสมต่อการมีสมาธิหรือไม่ หากระบบตรวจพบว่าแสงในห้องน้อยเกินไป มีการเคลื่อนไหวรบกวน และมีเสียงดังพร้อมกันในช่วงเวลาเดียวกัน จะถือว่าสภาพแวดล้อมไม่เอื้อต่อการโฟกัส และแจ้งเตือนผู้ใช้ทันทีผ่าน LED และ Buzzer เพื่อให้รู้ตัวและปรับสภาพแวดล้อมได้ทันเวลา นอกจากนี้ระบบยังส่งข้อมูลที่ตรวจวัดได้ขึ้น Cloud อย่างต่อเนื่อง เพื่อนำไปวิเคราะห์แนวโน้มและแสดงผลผ่าน Dashboard แบบเรียลไทม์ ทั้งบนมือถือและเว็บ ทำให้ผู้ใช้สามารถย้อนดูช่วงเวลาที่มีสมาธิดีหรือไม่ดีในแต่ละวันได้ เพื่อวางแผนปรับพฤติกรรมการทำงานหรือการเรียนให้มีประสิทธิภาพมากขึ้น

ระบบแจ้งเตือนการลืมปิดประตูตู้เย็น
(Smart Refrigerator Door Alert)

ระบบแจ้งเตือนการลืมปิดประตูตู้เย็น ใช้เซนเซอร์วัดแสงร่วมกับเซนเซอร์วัดระยะตรวจจับประตูที่เปิดค้างนานเกินไป แล้วแจ้งเตือนทันทีด้วย LED และ Buzzer

ระบบแจ้งเตือนการลืมปิดประตูตู้เย็นที่ใช้เซนเซอร์วัดแสงร่วมกับเซนเซอร์วัดระยะ (Ultrasonic Sensor) เพื่อตรวจจับว่าประตูตู้เย็นถูกเปิดทิ้งไว้นานเกินไปหรือไม่ โดยเซนเซอร์วัดระยะจะคอยตรวจสอบตำแหน่งของประตู ในขณะที่เซนเซอร์วัดแสงช่วยยืนยันสถานะการเปิด-ปิดให้แม่นยำยิ่งขึ้น หากตรวจพบว่าประตูเปิดค้างต่อเนื่องเกิน 5 วินาที ระบบจะแจ้งเตือนผู้ใช้ทันทีผ่าน LED และเสียง Buzzer เพื่อป้องกันไม่ให้อาหารเสียหรือสิ้นเปลืองพลังงานไฟฟ้าโดยไม่จำเป็น และเมื่อผู้ใช้ปิดประตูหรือรับทราบการแจ้งเตือนแล้ว สามารถกดปุ่มรีเซ็ตเพื่อหยุดการแจ้งเตือนและให้ระบบกลับไปตรวจจับสถานะตามปกติ

Bangkok PM2.5 Prediction using Multiple Linear Regression

โปรเจกต์วิเคราะห์ข้อมูลคุณภาพอากาศและค่าฝุ่น PM2.5 ในกรุงเทพมหานคร โดยใช้ Python และ Google Colab พร้อมพัฒนาโมเดล Multiple Linear Regression เพื่อพยากรณ์ค่า PM2.5 จากข้อมูลมลพิษทางอากาศ

โปรเจกต์นี้เป็นการวิเคราะห์ข้อมูลคุณภาพอากาศในกรุงเทพมหานคร และพัฒนาโมเดล Machine Learning สำหรับพยากรณ์ค่า PM2.5 โดยใช้ข้อมูลมลพิษทางอากาศ ได้แก่ PM10, O₃, NO₂, SO₂ และ CO ผ่าน Python และ Google Colab

  • Data Cleaning และจัดการ Missing Values ด้วย Pandas
  • แปลงข้อมูลวันที่และสร้าง Features เช่น Month, Day of Week และ Season
  • สร้าง Rolling Average Features เพื่อวิเคราะห์แนวโน้มของข้อมูลคุณภาพอากาศ
  • เตรียมข้อมูลสำหรับ Machine Learning และปรับ Scale ของข้อมูลด้วย RobustScaler
  • พัฒนาโมเดล Multiple Linear Regression ด้วย Scikit-learn
  • ประเมินประสิทธิภาพของโมเดลด้วย R² Score, RMSE และ MAE
  • สร้าง Visualization เพื่อเปรียบเทียบค่าจริง และค่าที่โมเดลพยากรณ์
  • ทดลองพยากรณ์ค่า PM2.5 จากข้อมูลมลพิษชุดใหม่
